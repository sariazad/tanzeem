# دليل المستخدم

## الدخول

- **العنوان:** افتح `/login`، وأدخل البريد أو اسم المستخدم وكلمة المرور.
- **حساب الجهة:** إن كان AD مفعّلاً، اختر «حساب الجهة (AD)». وإن كان الدخول الموحد مفعّلاً، اضغط زره.
- **التحقق الثنائي:** إن كان مطلوباً لدورك، امسح الرمز بتطبيق المصادقة (Microsoft أو Google Authenticator) في أول دخول. بعدها يُطلب منك الرمز في كل دخول.
- **اللغة والوضع:** من الشريط العلوي، بزر `EN`/`ع` والوضع الفاتح/الداكن. تُحفظ على جهازك.

## لوحة التحكم

تعرض لحظياً:
- **مؤشرات:** الفعاليات النشطة، الحضور الآن، الزوار اليوم، نسبة الحضور، الدعوات المؤكدة، الأجهزة المتصلة.
- **رسم:** الدخول والخروج بالساعة.
- **أقسام:** التنبيهات، والفعاليات الجارية مع توقّع الازدحام، وأحدث العمليات، والفعاليات القادمة.

## الفعاليات

### إنشاء فعالية

اضغط **«فعالية جديدة»** واتبع الخطوات الست:
1. **البيانات الأساسية:** العنوان، النوع، الوقت، السعة، المنظم.
2. **الموقع والمناطق:** موقع مسجل، أو موقع جديد بمناطقه.
3. **نموذج التسجيل.**
4. **قالب البطاقة:** مع معاينة.
5. **الدعوات:** اختيار مجموعات.
6. **النشر:** أو الحفظ كمسودة.

### صفحة الفعالية

| التبويب | ما فيه |
|---|---|
| نظرة عامة | المؤشرات والمسجلون وحالة الدعوات |
| الدعوات | راجع القسم التالي |
| الجدول | الجلسات حسب الأيام والمسارات، والبحث والفلترة، والجلسات المميزة بإطار ذهبي، وإدارة المتحدثين |
| تتبع الحضور المباشر | الإشغال، ومعدل الدخول، وتوقّع الازدحام، والرسم بالساعة، وكثافة المناطق، والخريطة الحرارية (منطقة × ساعة)، وسجل مباشر |
| خريطة الفعالية | المخطط بألوان الكثافة. **تحرير المخطط:** ارفع SVG أو صورة، واسحب المناطق، وغيّر حجمها من المربع الأزرق، ثم احفظ |
| الشبكات الذكية | مؤشرات التفاعل، وتوصيات ربط المشاركين ذوي الاهتمامات المشتركة. زر «ربط» يسجل التعارف |

**قائمة «المزيد»:** تغيير الحالة (نشر، بدء، إنهاء، إلغاء)، ونسخ رابط التسجيل المفتوح، والتقرير، والأرشفة.

### الدعوات

1. اضغط **«إضافة مدعوين»** واختر المصدر: أفراد بالبحث، أو مجموعات، أو ملف Excel (القالب متاح للتنزيل)، أو Active Directory.
2. اختر القناة (بريد، رسالة نصية، كلاهما، أو رابط فقط) ولغة الرسالة.
3. **تتبع الحالة:** لم تُرسل، مرسلة، مؤكدة، معتذر، ملغاة، منتهية، فشل الإرسال.
4. **إجراءات على المحدد:** إعادة إرسال، تذكير، جدولة تذكير.
5. **إجراءات لكل مدعو:** نسخ رابط الدعوة، تأكيد نيابة عنه، إلغاء الدعوة (يُبطل رمز الدخول).

## الزيارات

1. أنشئ **«زيارة جديدة»**. تبدأ بحالة «طلب».
2. يعتمدها صاحب صلاحية **اعتماد**، أو يرفضها مع ذكر السبب.
3. أضف المشاركين: أفراداً، أو مجموعة، أو أشخاصاً جدداً.
4. **«إصدار التصاريح»** يُصدر QR لكل مشارك ويرسله.
5. الدخول والخروج يحدّثان الحالة تلقائياً.
6. يتوفر عرض «تقويم» شهري.

## الزوار والمجموعات

**الزوار:**
- السجل موحّد، ويُطابق تلقائياً بالهوية ثم الجوال ثم البريد لمنع التكرار.
- **ملف الزائر:** البيانات، وكشف رقم الهوية (يُسجَّل في التدقيق)، وسجل الفعاليات والزيارات، وسجل الدخول والخروج.
- **إجراءات:** التواصل المباشر بالبريد أو الرسائل النصية، والحظر مع السبب.
- **تبويب «قائمة الحظر»:** المحظورون. محاولة دخولهم تنبّه الأمن فوراً.

**المجموعات:** وفد، أو دفعة طلاب، أو منسوبو جهة. تُستخدم للدعوات والحضور الجماعي.

## تسجيل الحضور (الاستقبال)

1. اختر الفعالية أو الزيارة، والعملية (تلقائي، دخول، خروج)، والبوابة.
2. **المسح:** بالماسح اليدوي (المؤشر في حقل المسح) أو بالكاميرا.
3. **النتيجة:** تظهر بلون وصوت (أخضر للدخول، برتقالي للخروج، أحمر للرفض)، ومعها السبب.
4. **البحث اليدوي:** بالاسم أو الجوال أو رقم الهوية، ثم «دخول» أو «خروج».
5. **الطباعة:** «طباعة البطاقة» بنقرة، أو فعّل الطباعة التلقائية.
6. **الوضع الاحتياطي دون اتصال:**
   - نزّل «حزمة دون اتصال» مسبقاً.
   - عند انقطاع الشبكة يستمر التحقق من الحزمة، وتُحفظ العمليات.
   - تُزامن تلقائياً عند عودة الاتصال، أو بزر «مزامنة الآن».

## الحضور الجماعي

1. اختر الفعالية أو الزيارة، ثم المجموعة.
2. أزل علامة من تريد استثناءه.
3. اضغط «تسجيل دخول N» أو «تسجيل خروج N».
4. يظهر ملخص لمن لم يُسجَّل وسببه.

## التقارير

**التقارير السبعة:** الحضور، أوقات الدخول والخروج، نسب المشاركة، الأداء، الزيارات، الزوار، الأجهزة.

- **الفلترة:** بالتاريخ والفعالية والجهة.
- **التصدير:** Excel أو CSV أو PDF (طباعة).
- **«ملخص ذكي»:** ملخص للتقرير.
- **«التقارير المجدولة»:** إرسال تقرير بالبريد يومياً أو أسبوعياً أو شهرياً.

## الإشعارات

- تنبيهات مصنفة حسب الأولوية والحالة: ازدحام منطقة، اكتمال السعة، جهاز منقطع، ورق منخفض، زائر محظور، فشل تكامل، قفل حساب.
- **الإجراءات:** فتح العنصر، أو استلام، أو «تمت المعالجة».
- **«إرسال تنبيه للمشاركين»:** يظهر فوراً في تطبيقهم.

## تطبيق الجوال

**المشارك:** يفتح رابط الدعوة، ثم:
- يؤكد ويعبّئ النموذج.
- في «بطاقتي» رمز QR يعمل دون اتصال.
- يتصفح الجدول والخريطة.
- يستقبل التنبيهات.
- في «التعارف» يرى توصيات ويضيف اهتماماته.

**المنظم:** `/m/o`، ثم:
- يختار الفعالية.
- يمسح بالكاميرا ويرى الأعداد لحظياً.
- يرسل تنبيهاً للمشاركين.
