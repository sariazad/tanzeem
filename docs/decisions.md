# سجل القرارات (ADR)

كل قرار خرج فيه التنفيذ عن البرومبت الأصلي، أو حُسم فيه أمر غامض، موثّق هنا مع سببه.

## 1. خادم Node.js واحد بدل Next.js + NestJS + PostgreSQL + Redis

- **السياق:** المطلوب أن يُستضاف النظام على Serv00 بنفس نمط «درب»، برابط فرعي منفصل.
  - Serv00 خادم FreeBSD مشترك، فيه 512MB ذاكرة، و20 عملية للحساب، ولا يدعم Docker.
  - Next.js وNestJS وRedis وBullMQ لا تعمل ضمن هذه الحدود. Next.js وحده يستهلك الذاكرة كلها.
- **القرار:** عملية Node 22 واحدة (`server/`)، تجمع:
  - **قاعدة البيانات:** `node:sqlite` المدمجة، بوضع WAL.
  - **التحديث اللحظي:** WebSocket عبر مكتبة `ws`.
  - **الواجهة:** JavaScript بلا إطار، تُبنى بـ Vite، مع تقسيم الحزم لكل صفحة.
- **ما حافظنا عليه من روح المطلوب:**
  - **API-first:** كل وظيفة متاحة عبر REST موثّق بـ OpenAPI، والواجهات عملاء له فقط.
  - **Modular:** كل وحدة بخدمة مستقلة في `server/services/`. الموارد معرّفة مرة واحدة في `shared/resources.js`، ومنها يتولّد الـ CRUD والتحقق والتوثيق.
  - **On-Prem:** يوجد Docker Compose وNginx وسكربت تنصيب بأمر واحد لخوادم الجهة.
- **الترقية لاحقاً:** طبقة البيانات معزولة، والاستعلامات SQL قياسية. الانتقال إلى PostgreSQL ممكن عند الحاجة لأكثر من خادم.

## 2. جلسات على الخادم بدل JWT + Refresh

- **السبب:** المطلوب «إجبار تسجيل الخروج» و«الجلسات النشطة»، وهذان يحتاجان إلغاءً فورياً.
  - رمز JWT لا يُلغى قبل انتهاء صلاحيته.
- **القرار:** الجلسة رمز عشوائي في كوكي `HttpOnly; SameSite=Lax`، وتُخزَّن تجزئته فقط في القاعدة.
  - انتهاء بعد خمول قابل للضبط.
  - حماية CSRF بترويسة `X-Requested-With`.
- **للأنظمة الأخرى:** مفاتيح API تُرسل في الترويسة `X-API-Key`، ولكل مفتاح دور.
- **للأجهزة:** رمز جهاز يُرسل في الترويسة `X-Device-Token`.

## 3. SAML عبر وسيط هوية

- **السبب:** تنفيذ SAML 2.0 مباشرة يتطلب مكتبات توقيع XML ثقيلة، ومعروفة بثغرات.
- **القرار:** OIDC أصلي (Authorization Code + PKCE)، مع التحقق من توقيع `id_token` عبر JWKS.
  - SAML يُدعم عبر Keycloak أو ADFS أو Azure AD كوسيط.
  - بيئة اختبار جاهزة في `docker-compose.idp.yml`.

## 4. تطبيق الجوال PWA بدل React Native

- **السبب:**
  - تطبيق Expo يحتاج نشراً في المتاجر وحسابات مطوّر.
  - المدعو يصله رابط، فالأنسب أن تفتح صفحته فوراً دون تثبيت.
- **القرار:** PWA على `/m` بوضعين، المنظم والمشارك.
  - يُثبَّت على الشاشة الرئيسية، والبطاقة تعمل دون اتصال.
  - إشعارات المتصفح، وكاميرا المسح.
  - Apple/Google Wallet اختياري: يتطلب شهادات المتاجر، ولم يُنفَّذ.

## 5. الطباعة: المتصفح أولاً، وPrint Agent لطابعات Zebra

- **الطباعة من الكشك:** Chrome بوضع `--kiosk --kiosk-printing` يطبع بصمت على الطابعة الافتراضية، مثل Evolis بتعريفها.
  - البطاقة SVG بالمقاس الحقيقي.
- **طابعات Zebra الشبكية:** `tools/print-agent/agent.mjs` يستقبل أوامر ZPL عبر WebSocket، ويرسلها للطابعة على المنفذ 9100.
  - يرسل نبضات وحالة الورق عبر `~HS`.
- **بلا طابعة:** معاينة تُطبع كملف PDF من المتصفح، كما تنص معايير القبول.

## 6. رموز QR

- **محتوى الرمز:** `TZ1.<رقم الاعتماد>.<HMAC-SHA256 مختصر 128 بت>` فقط. لا يحمل أي بيانات شخصية.
- **إبطال الرمز:** يتم بتدوير `nonce`.
- **التحقق دون اتصال:** يُنزَّل للجهاز بصمات SHA-256 للرموز، مع الأسماء فقط، دون هوية أو جوال.
  - العمليات تُخزَّن وتُزامن لاحقاً.
  - التعارض، أي الدخول المزدوج، يُكشف ويُنبَّه عليه.
- **منع الدخول المزدوج:** من جدول `presence`. لا دخول ثانٍ قبل تسجيل خروج.

## 7. التشفير

- **رقم الهوية:**
  - يُخزَّن مشفّراً بـ AES-256-GCM.
  - تُحفظ تجزئة HMAC للبحث المطابق.
  - تُحفظ آخر 4 أرقام للعرض.
  - كشف الرقم كاملاً يُسجَّل في سجل التدقيق.
- **إعدادات التكاملات:** مشفّرة كذلك، والقيم السرية لا تُعاد للواجهة أبداً.
- **المفاتيح:** كلها مشتقة من `APP_SECRET`، فيجب عدم تغييره بعد التشغيل.

## 8. سجل التدقيق

- **الحماية من التعديل:** إضافة فقط. مشغّلات SQLite (`RAISE(ABORT)`) تمنع التعديل والحذف.
- **كشف العبث:** كل سطر يحمل تجزئة السطر السابق، فيُكشف أي تعديل خارج النظام.
  - التحقق متاح من الواجهة، ومن سطر الأوامر: `cli verify-audit`.
- **البيانات الحساسة:** تُحجب من القيم قبل/بعد.

## 9. المزوّدون القابلون للتبديل

- **البريد:** SMTP عبر nodemailer.
  - بلا ضبط: الرسائل تُسجَّل فقط، وروابط الدعوات تظهر للنسخ. مناسب للتجربة على Serv00.
- **الرسائل النصية:** محوّل HTTP عام بقالب طلب، يناسب مزودي الرسائل المحليين، مع وضع «سجل فقط».
- **الذكاء الاصطناعي:**
  - **المزوّد المدمج:** خوارزميات محلية بلا اتصال خارجي، لأن البيئة On-Prem.
    - توقّع الازدحام: من معدل الدخول في آخر 30 دقيقة.
    - التوصيات: تشابه Jaccard للاهتمامات، مع تفضيل تنوع الجهات.
  - **مزوّد اختياري:** نموذج لغوي متوافق مع OpenAI داخل الشبكة، لملخصات التقارير.
  - الوحدة كلها قابلة للتعطيل.
- **التقويم:** موجز ICS يُشترك به من Exchange أو Google.
  - مزامنة Graph API ثنائية الاتجاه مؤجلة، لأنها تتطلب تسجيل تطبيق في Azure لدى الجهة.

## 10. Excel

- **الخادم:** يكتب xlsx بكاتب مدمج صغير (OOXML + ZIP)، بلا مكتبات تحليل.
  - مكتبة SheetJS المنشورة على npm فيها ثغرات معروفة بلا إصلاح.
- **التحليل:** الاستيراد يُحلَّل في متصفح المستخدم فقط، ويُرسل للخادم كصفوف JSON تُتحقق حقلاً حقلاً.
- **النتيجة:** `npm audit --omit=dev` بلا ثغرات.

## 11. PDF

- التقارير والبطاقات تُطبع إلى PDF من المتصفح، بأوراق طباعة مخصصة (`@media print` و`@page`).
- السبب: مكتبات توليد PDF على الخادم مع العربية والتشكيل ثقيلة وضعيفة الدعم.

## 12. المنطقة الزمنية والتقويم

- **التخزين:** كل الأوقات تُخزَّن بتوقيت UTC بصيغة ISO.
- **العرض:** بتوقيت الرياض.
- **التقويم:** ميلادي وهجري (أم القرى) عبر `Intl`، والاختيار من إعدادات الهوية.

## 13. حماية البيانات الشخصية (PDPL)

- **سياسة الاحتفاظ:** قابلة للضبط، وافتراضها 730 يوماً لبيانات الزائر غير النشط.
  - بعد المدة تُخفى الهوية: الاسم والجوال والبريد والهوية والصورة.
  - يُستثنى المحظورون ومن لديهم فعاليات قادمة.
- **السجلات:** بلا بيانات شخصية. المسارات بالمعرّفات فقط، وروابط الدعوات مُقنّعة.
