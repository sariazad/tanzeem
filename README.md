# تنظيم — المنظومة الذكية لإدارة الفعاليات والزوار

> «تكامل رقمي بمعايير وطنية»

منصة متكاملة تُنصَّب على خوادم الجهة (On-Prem)، وتغطي دورة حياة الفعالية والزيارة كاملة:
- الدعوة والتسجيل المسبق.
- التحقق برمز QR موقّع وتسجيل الدخول والخروج.
- طباعة البطاقات فوراً من أكشاك الخدمة الذاتية.
- التقارير والتحليلات اللحظية.

النظام ثنائي اللغة بالكامل (عربي RTL / إنجليزي LTR)، وهوية الجهة قابلة للتخصيص من الإعدادات دون تعديل الكود.

**التجربة:** https://tanzeem.sari221.serv00.net

## الواجهات

| الواجهة | الرابط | لمن |
|---|---|---|
| لوحة التحكم | `/app` | 16 صفحة بالترتيب المعتمد، وتحت الفعالية 5 صفحات فرعية (الدعوات، الجدول، تتبع الحضور المباشر، خريطة الفعالية، الشبكات الذكية) |
| الكشك | `/kiosk` | واجهة لمس بملء الشاشة. تُربط برمز من 6 أرقام وتطبع البطاقة |
| تطبيق الجوال (PWA) | `/m` | **المشارك:** الدعوة وتأكيدها، بطاقة QR تعمل دون اتصال، الجدول، الخريطة، التنبيهات، التعارف. **المنظم:** المسح بالكاميرا والأعداد اللحظية والتنبيه |
| صفحة الدعوة | `/m/i/<رمز>` | الرابط الذي يصل المدعو بالبريد أو الرسالة النصية |
| التسجيل المفتوح | `/m/r/<رقم الفعالية>` | يسجّل فيه أي شخص في الفعاليات التي تسمح بالتسجيل الفوري |
| توثيق الـ API | `/docs` · `/api/openapi.json` | OpenAPI 3.1، جاهز للاستيراد في بوابة API Management |
| Print Agent | `tools/print-agent/agent.mjs` | يطبع على طابعات Zebra عبر الشبكة (ZPL) أو على طابعة النظام |

## التشغيل محلياً

```sh
npm install
npm run build
cp .env.example .env            # ضع APP_SECRET و DEMO_PASSWORD
npm start                       # http://localhost:3000
node server/cli.js admin you@example.com "الاسم"
```

مع `SEED_DEMO=1` تُضاف بيانات تجريبية واقعية عند أول تشغيل:
- 7 جهات، و5 فعاليات، و300 زائر.
- دعوات وزيارات ومجموعات وأجهزة.
- سجلات حضور لفعالية جارية.
- حسابات تجريبية لكل دور، كلمة مرورها `DEMO_PASSWORD`: `superadmin@` و`orgadmin@` و`organizer@` و`reception@` و`it@`، كلها على النطاق `tanzeem.demo`.

## الاختبارات

```sh
node tests/lint.mjs            # الترجمة: كل مفتاح موجود بالعربية والإنجليزية، ولا نصوص مكتوبة مباشرة
npx vitest run                 # 45 اختبار وحدات وتكامل API، منها الرحلة الكاملة لمعايير القبول
node tests/load.mjs            # الذروة: 1200 تحقق متزامن (الهدف ≥1000/دقيقة و p95 < 500ms)
npx playwright test            # 5 تدفقات حرجة في متصفح حقيقي
```

النتائج المقاسة فعلاً:

| القياس | النتيجة |
|---|---|
| معدل التحقق | حوالي 40,000 تحقق في الدقيقة |
| زمن التحقق p95 عند الخادم | حوالي 48ms، تحت ضغط 25 جهازاً متزامناً |
